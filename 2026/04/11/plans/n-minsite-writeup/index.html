N-MinSite CTF 解题方案

题目信息

  • 目标: http://114.66.24.221:35708
  • CMS: MaxSite CMS (PHP/8.1.33 + Apache/2.4.62 Debian)
  • 框架: CodeIgniter Session
  • FLAG 位置: /admin 页面（需要管理员权限）
  • Admin Bot: 每隔一段时间访问首页

已收集的关键信息

首页关键提示

  1. 首页从 /pages/ 目录下的 .html/.htm 文件直接组装，无过滤
  2. “Writers use the same content mirror as the page uploader” — 有页面上传机制
  3. “Administrators only like to read the first article” — Admin Bot 只读第一篇文章
  4. 现有文件: maintenance-notice.html（第一篇）, welcome.html（第二篇）

上传方式分析

/update-maxsite/ 端点始终返回 “Access is denied”，可能的原因：

  1. 需要管理员 session（最可能）
  2. IP 白名单限制
  3. 需要特定的认证方式

推荐尝试的上传方法（按优先级）：

方法1: 通过 update-maxsite 上传 ZIP

MaxSite CMS 的更新机制通常接受 ZIP 文件并解压到站点根目录。需要管理员权限。

方法2: 利用 require-maxsite 写文件

require-maxsite 是一个文件包含端点，可能可以利用 PHP wrapper 写入文件。

方法3: 利用评论XSS获取Admin Cookie，再用Admin权限上传

其他可能的攻击向量

  1. MaxSite CMS 已知CVE: 搜索 MaxSite CMS 的已知文件上传漏洞
  2. CI Session 伪造: 如果能找到 CodeIgniter 的加密密钥，可以伪造管理员 session
  3. SQL注入: 通过评论或其他表单注入，修改用户权限为管理员
  4. 路径穿越: 通过 require-maxsite 的 base64 路径包含敏感文件
  5. SSRF: 通过某个功能让服务器自己访问 update-maxsite 端点
